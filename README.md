# AnyApis Desktop

AnyApis lets AI work with files and tools in your local workspace. Configure your AnyApis API key to get started.

- Website and downloads: https://app.anyapis.link/download/
- Service email: anyapis5@gmail.com
- macOS: Apple Silicon, macOS 13 or later.

## Installation

Download the DMG from Releases, open it and drag AnyApis into Applications. The current preview uses an ad-hoc signature and is not notarized. Follow the installation guide on the website if macOS blocks opening.

Compare the downloaded file with `SHA256SUMS.txt`. Releases use immutable versioned filenames.
